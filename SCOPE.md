# Phạm vi MVP — LMS Classroom (Phụ lục báo cáo)

Tóm tắt nhanh; chi tiết xem `docs/01-gioi-thieu.md` và `docs/02-phan-tich-yeu-cau.md`.

## Bắt buộc
- Roles: Teacher, Student (Auth Service tách)
- Class create/join bằng mã
- Post + Comment
- Material theo Class
- Exercise → Submission → Grade
- Expo RN + Core API + Auth Service (greenfield)

## Ngoài MVP
- Admin web nặng, attendance, analytics/risk worker, gRPC, Redis, Socket bắt buộc, S3/LocalStack, push thật
